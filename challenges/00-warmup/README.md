# Warmup - Tier 1

This one exists so you can confirm your setup works before the real challenges. It is not
supposed to be hard.

The test forks Ethereum mainnet at block 21895252 and gives your address 10 ETH. Write code
in `test_Solution()` that leaves you holding at least 1 WETH.

Check it with:

```
python alpha.py check 00
```
