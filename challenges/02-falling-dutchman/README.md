# Falling Dutchman - Tier 2

Some time ago, Gnosis developed a decentralized trading protocol called [DutchX](https://dutchx.readthedocs.io/en/latest/). Over time this protocol was deprecated, and it was later superseded by COW Protocol, which has now processed hundreds of billions in volume. Auctions back then were not so efficient as they are now.

Can you execute a trade on the [exchange](https://etherscan.io/address/0xb9812E2fA995EC53B5b6DF34d21f9304762C5497) at block 9462777 in 2020, and turn your 0.1 ETH into at least 4 ETH?

Run the test case with:

```
python alpha.py check 02
```
